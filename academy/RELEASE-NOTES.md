# Guild Command Hall 1.0.0

Initial complete release.

## Guild operations

- Commander’s Intent, Campaign Board, weekly Guild Rhythm, and upcoming-event display.
- Local `.ics` calendar import plus direct Google Calendar road.
- Whole-Fighter Doctrine tracker for Body, Craft, Mind, Character, and Fellowship.
- Structured War Journal after-action reviews and synchronized Field Ledger notes.
- Shared Iron Ward focus protocol with four durations and optional completion signal.

## Connected resources

- Verified Guild Drive, F100 Courses, Core/Admin, Fighter Coach, ORK, Amtgard Resources, and official Documents roads.
- Editable Resource Hall with right-click page capture.
- Optional local bookmark discovery for Guild and social destinations.
- Unconfigured YouTube, Facebook, Instagram, and Patreon slots are never assigned guessed addresses.

## Presentation

- Original Guild sword-and-book heraldic crest and Chrome icons.
- Responsive obsidian great hall with crimson banners, heraldic gold, rose-window light, stone vaults, and rising embers.
- Gold, Crimson, Forest, and Sapphire standards; full, system-controlled, or reduced motion.
- Optional Obsidian & Gold Chrome-frame theme.

## Privacy and durability

- No trackers, analytics, advertising, accounts, host permissions, content scripts, or remote executable code.
- Bookmark access remains optional and revocable.
- Calendar import reads only a user-selected local file; no Google account access.
- Local JSON export, validated import, and complete reset.
- Manifest V3, restrictive Content Security Policy, URL-scheme validation, bounded imported data, and no external runtime dependencies.
